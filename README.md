## 🌱 프로젝트 소개

**KOSPOCARD**는 업무 중 주고받는 명함을 보다 편리하게 정리하고 활용하기 위해 개발한 안드로이드 애플리케이션입니다.

한국남부발전 직원들의 자율 기술공유 커뮤니티인 **AI-DATA Lab in KOSPO**에서 공유하는 첫 번째 프로젝트로, 생성형 AI와 자연어 기반 개발 방식인 **바이브 코딩(Vibe Coding)**을 활용한 업무개선 사례입니다.

> **AI First! KOSPO!**  
> 현장의 아이디어를 AI와 함께 실제 도구로 구현합니다.

## ✨ 주요 기능

| 기능 | 설명 |
| --- | --- |
| 📷 명함 등록 | 카메라로 명함을 촬영하거나 갤러리에서 이미지 불러오기 |
| 🤖 AI 정보 인식 | 이름, 회사·소속, 직위, 연락처 등 명함 정보 인식 및 입력 지원 |
| 🔎 명함 검색·관리 | 저장된 명함 조회, 검색, 수정 및 삭제 |
| 🔗 정보 공유 | QR코드 및 텍스트 방식으로 명함 정보 공유 |
| 📱 연락처 연동 | 인식한 정보를 스마트폰 연락처에 등록 |
| 💾 데이터 백업 | 명함 관리 자료 백업 기능 |

※ 인식 결과는 명함 이미지 품질과 기재 형식에 따라 달라질 수 있으므로 저장 전에 확인해 주세요.

## 💡 개발 배경: 바이브 코딩

바이브 코딩은 구현하고 싶은 기능을 자연어로 설명하고, 생성형 AI가 제안한 코드를 검토·수정하면서 소프트웨어를 개발하는 방식입니다.

KOSPOCARD는 일상적인 업무 불편을 출발점으로 삼아, 필요한 기능을 직접 기획하고 AI를 활용해 구현한 사례입니다. 이를 통해 생성형 AI가 문서 작성이나 정보 검색을 넘어 **실제 업무용 프로그램 개발**에도 활용될 수 있음을 보여주고자 합니다.

## 🌍 English Overview

**KOSPOCARD** is an Android business card management app developed using generative AI and a **vibe coding** approach. It supports capturing business cards, extracting contact details, searching and editing saved records, sharing information, and backing up data.

This repository is maintained as part of **AI-DATA Lab in KOSPO**, a voluntary employee-led AI and data knowledge-sharing community. Source code and build instructions will be added after the required security, intellectual property, and licensing reviews.

**Distribution:** The APK is not intended for public distribution. Internal availability is planned through the company's mobile device management (MDM) system.
